| Clipping for a paid campaign is authorised, so it is the safe route | verified | In a campaign the content owner pays for clips, so use is licensed under the campaign terms; terms vary, so read each campaign's rules. |
| Tagging or crediting the creator makes clipping safe | unverified | Credit is not a licence. Copyright is a separate matter from YouTube monetization, and a [YouTube policy summary](https://support.google.com/youtube/answer/1311392?hl=en) says reused content needs a meaningful difference from the source. |
| Reused content is only a little icky if sufficiently edited | partly verified | YouTube permits clips and commentary that add meaningful value, and may remove monetization for the whole channel if it cannot tell you made the content original. |
| Copyright has never been an issue | unverified | Personal experience; it is not evidence that it is safe, and it is an absolute claim contradicted by takedown and monetization policies. |

Overall: The paid-campaign route is sound; the 'just tag them, it's never a problem' route is overconfident, and the post is an affiliate promotion.
