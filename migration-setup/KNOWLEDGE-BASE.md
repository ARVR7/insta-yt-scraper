# KNOWLEDGE BASE: file map, every active lesson, incidents, report digests, tools

## Start here (6 lines)
1. This file is the index. The procedure itself is PIPELINE.md (this folder) and `.claude/skills/clips/SKILL.md`.
2. Section A = where everything lives. B = all 104 ACTIVE lessons (the user's preferences, rules, gotchas, decisions, tool notes). C = incidents and the checks that enforce them. D = what each report/research doc concluded. E = third-party tools and licences.
3. Before any clip job run `python3 .claude/skills/lessons/scripts/query.py --stage plan,download,moments,render,layout,captions,zoom,facecam,publish,infra --retros 3` (prints every active lesson, the source of truth; section B is a snapshot of `lessons/INDEX.md`, generated, 2026-11-16).
4. Newer wins: `SKILL.md` and dated reports beat `PLAN.md` (stale in places, see PIPELINE.md section 13) and `.claude/REQUIREMENTS.md` (partly stale: e.g. it still lists voice-over as TODO although highlights commentary is built).
5. Items marked "local only" are NOT in git (source videos, masters, `docs/cache/`, window files); a fresh clone does not have them.
6. No secret values are stored anywhere in this repo; only env variable NAMES are documented.
