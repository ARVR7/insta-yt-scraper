## Caption / description
Want to start a new page but you have zero videos? Same 😂

There’s a free toolbox on GitHub called lemo-opuscar. It gives Claude Code 59 film styles: watercolor, crayon picture book, pixel game, Japanese woodblock, 50s cartoon, tiny toy city and 53 more.

1. Paste two lines into Claude Code to install it
2. Pick ONE style that fits your page
3. Give Claude a style and a story. It draws it, adds music and narrates it (about 30-60 min per film)
4. One style. One topic. Post every day.

Free and open source (MIT). Needs Node 20+, ffmpeg and Python 3.11+.

Comment FILM and I’ll send you all 59 styles + the prompts.

Style clips: lemo-opuscar by LemoLab (CC BY 4.0)
